# Exemplos de solicitação

- **Escopo:** “Use `data-project-scoping` para transformar esta demanda em problema, fontes, critérios de aceite, riscos e plano incremental.”
- **EDA:** “Use `data-analytics-eda` para analisar este CSV. Informe grão, qualidade, achados com evidências e limitações.”
- **SQL:** “Use `sql-data-analysis` para validar o grão e conferir se este join duplica transações. Proponha queries de reconciliação.”
- **Pipeline:** “Use `data-pipeline-engineering` para revisar a estratégia incremental e demonstrar que reexecutar o lote é idempotente.”
- **Databricks:** “Use `databricks-lakehouse` para completar as camadas Bronze, Silver e Gold usando as APIs compatíveis com o runtime informado.”
- **Governança:** “Use `data-quality-governance` para criar regras de qualidade, severidades, quarentena e responsáveis para este dataset.”
- **Cloud:** “Use `multicloud-data-architecture` para comparar opções Azure, AWS e GCP para estes requisitos; deixe premissas de custo explícitas.”
- **ML:** “Use `ml-model-development` para montar baseline, split sem leakage, métricas e análise de erro deste problema de classificação.”
- **RAG:** “Use `rag-knowledge-assistant` para desenhar um conjunto de avaliação com respostas suportadas, conflitos e perguntas sem evidência.”
- **Agentes:** “Use `ai-agent-engineering` para revisar ferramentas, permissões, retries, limites, auditoria e pontos de aprovação humana.”
- **Code review:** “Use `ai-data-code-review` para revisar este diff. Liste apenas achados acionáveis com evidências e severidade.”
- **Documentação:** “Use `technical-data-documentation` para criar um README coerente com o código. Marque explicitamente o que não foi verificado.”
